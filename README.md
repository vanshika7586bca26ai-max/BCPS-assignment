Project 1: Command-Line Folder and File Management

Aim

To learn how to create, navigate, list, and manage files and folders using command-line commands.

Tools Used

- Command Prompt (Windows) or Terminal (Linux)
- Basic command-line commands

Commands and Their Uses

Command| Purpose
"mkdir"| Creates a new directory
"cd"| Changes the current directory
"dir"| Lists files and folders in Windows
"ls"| Lists files and folders in Linux
"type"| Displays a text file's contents in Windows
"rmdir"| Removes an empty directory
"del"| Deletes a file in Windows

Procedure

1. Open Command Prompt or Terminal.
2. Create a new folder using "mkdir".
3. Navigate into the folder using "cd".
4. List its contents using "dir" or "ls".
5. Create and view a sample text file.
6. Create a subfolder and remove it when empty.
7. Verify the results using the appropriate commands.

Example Commands (Windows)

mkdir BCPS_Project
cd BCPS_Project
mkdir Practice
dir
cd Practice
cd ..
rmdir Practice

Expected Outcome

The user learns basic command-line navigation and file-management operations.

Conclusion

This practical introduces essential command-line skills for organizing and managing files and directories.

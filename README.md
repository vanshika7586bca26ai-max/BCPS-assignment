## Lab Assignments

### Module 1: Command-Line Interface

**Lab 1 – Basic File Management**
- Create, navigate, list, and remove directories using CLI commands.
- Practise commands such as `mkdir`, `cd`, `dir` and `rmdir`.

**Lab 2 – File and Folder Management**
- Perform file and directory operations using command-line tools.
- Practise creating, copying, renaming, moving, and managing files.

**Lab 3 – System Configuration and Networking**
- Explore system information and basic network diagnostics.
- Practise commands such as `ver`, `hostname`, `systeminfo`, `ipconfig`, `ping`, `nslookup` and `curl`.

### Module 2: LibreOffice Writer

**Lab 4 – Professional Document Formatting**

- Create tables, headers, footers, and page numbers.

**Lab 5 – Mail Merge**
- Create personalised invitation letters using Mail Merge.
- Practise combining a data source with a document template.

**Lab 6 – Student Marksheet**

**Lab 7 – Attendance and Salary Calculation**
- Create spreadsheets for attendance tracking and salary calculations.

**Lab 8 – Inventory Management**
- Organise inventory data and track item quantities using a spreadsheet.

### Module 4: LibreOffice Impress

**Lab 9 – Educational Presentation**
